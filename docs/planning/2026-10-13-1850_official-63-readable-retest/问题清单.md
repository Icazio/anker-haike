# 问题分别归谁处理

[返回整体情况](整体情况.md)。本页中的“系统”是客服程序及模型决策，“Agent边界”是助手缺少工具、权限或事实；“官方口径”是品牌需明确的政策和产品说明。一个案例可有多个原因，以下各表不能相加成失败总数。

## 系统本身需要改：有证据的8案

| 案例 | 问题和证据 | 应怎样改、怎样算验好 |
| --- | --- | --- |
| [T20](案例/T20.md) | rv-0090包含重建地图与重试，却只给文字后标结束；两次相同 | 含实际排障动作的答案应收结果；纯功能解释可结束。验证客户未反馈前不宣布排障完成 |
| [T31](案例/T31更新后复测.md) | 旧版检索有结果，知识选择模型超时，恢复后错误归为知识缺口 | 保留运行失败类型，相关候选可恢复重试；更新后3次正常。还需隔离验证超时分支，不能继续把本案列成“当前仍复现” |

| [T42](案例/T42.md) | 内部把手持塑料件与后方机器人底部合为主体；重复仍混淆 | 按独立物体记录部件、位置和置信程度；不能把后景金属触点归到手持件上 |

| [T52](案例/T52.md) | 主轮正常时长说明被编成动作卡；重复改用条目仍主要排查盒给泵充电 | 同时匹配设备、充电方向和症状；说明时长不能冒充故障检查。电源到盒无输入应有单独路线 |

其中T42、T48的本轮对外回复并没有造成已观察到的错误维修指令，缺陷在内部证据。T31的主轮故障属于旧运行版本。其余7案也没有在后续全部新版本上重跑，不能据这张表声称最新版本仍有8案失败。

## “知识库不执行”要分成几种情况

| 实际情况 | 案例 | 判断 |
| --- | --- | --- |
| 找到正确知识但选了其他对象 | T40 | 是选择问题，不是补一条重复知识就能解决 |
| 找到知识，但执行形态不完整 | T20；T52主轮 | 动作当说明直接结束，或说明当动作；需修执行组织 |
| 模型调用出错，最终没用上已有知识 | T31旧版 | 是运行与恢复问题，不是官方没资料 |
| 候选类似，但问题前提不适用 | T61；T52重复 | 不应为套条目反过来改写客户事实 |
| 条件还没确认，先问客户 | T19/T26/T38/T39/T46/T57 | 合理暂停，不能算不执行 |
| 当前资料缺少足够明确的答案 | T13/T34/T48 | 明确说明范围、收集信息、转人工；同时推动官方补齐 |

本轮没有证据证明这些问题来自知识库服务整体不可用。T31的检索成功与后续模型失败是不同环节。

## 意图不准：大类认对了，细节仍可能错

T40/T52/T61都能识别为设备问题，但分别丢了“清洁液”“盒自身输入充电”“已经提前启动”这些决定排障方向的细节。单看意图标签命中率，会掩盖这些错误。

T41的物流诉求已进入任务队列，不能写成“完全未识别物流”；问题是没有完整回应组合诉求。T50两次都没有把“左边能工作”翻成不能工作，只是问题略预设左右有差异，属于表达可优化。T57两次都先问App版本，当前没有跳过版本采集。

判断一个意图是否准确，应看“设备是谁、异常是什么、客户已做什么、还有什么目标”是否保留，而不是只看归入哪个大类。

T40的独立核查也有官方依据：清洁液检查需观察标记液位及特定清水消耗条件下的用量，湿拖布不是投液证明。[eufy清洁液使用说明](https://service.eufy.com/article-description/How-do-I-use-eufy-cleaning-solution-with-my-S1-Pro)。

T52官方网页确实把盒内触点、给泵充电和充电时长写在同篇，因此源资料组织与系统选用都需要改。[eufy充电盒说明](https://service.eufy.com/article-description/The-charging-case-cannot-charge-be-fully-charged)。

排程官方排查涵盖时间、网络和同步等因素，这支持把T61作为时间异常继续调查，但不足以认定其“提前两小时”由时区造成。[eufy排程排查说明](https://service.eufy.com/article-description/What-should-I-do-if-my-S1-Pro-does-not-start-cleaning-at-the-scheduled-time)。

## 语言与体验：不要和根本路线错误混算

主轮T6、T13、T18、T20、T21、T22、T28、T36、T37、T43共10案，非英语客户收到英语回答或卡片。应让对话、步骤、注意事项、售后材料要求都沿用客户语言；只翻译开场白不够。完整中文译文已写入逐案记录，原始英语也保留。

可继续优化但本轮不计入上述8案主问题的有：T16重复安装检查；T27应更清楚区分安装咔嗒声与运行异响；T43残留“<>”，且末轮补充动作后直接接售后，缺该动作单独反馈；T50可更中性地问具体诉求；T51过保后可说明可用服务渠道；T53到货按钮损坏问题与已使用多月关系弱。T43已有前序排障过程，严重程度与T20整段排障直接结束不同，但两者都值得统一动作反馈规则。

## Agent边界：该转就转，别虚构执行

助手可以解释资料、收集事实、提出方案、建立内部处理状态；当前没有证明它能实际拦截仓库发货、修改承运商状态、批准赔付换货或完成配件购买。T9、T44、T45、T47、T49、T59、T63等应按这个边界评价。

本轮也没有确认调查/补发方案、补填未知凭证或回答未知部件状态。因此“等待客户”“等待审核”是覆盖终点，不自动算失败，也不算已经办理完成。
