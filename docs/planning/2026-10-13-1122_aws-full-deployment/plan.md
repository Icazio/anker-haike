# AWS 完整部署设计

## 目标与范围

把本机运行的服务迁到 AWS，使用户电脑关机后客户页面、管理页面、会话、模型与知识检索仍可用。本轮交付可评审的架构、迁移顺序、验证门槛、费用和回退设计；不创建资源、不停服务、不迁移数据、不发布应用。

## 工作步骤

1. 核对 Compose、镜像、运行时配置、数据库与知识库持久化、发布脚本和现有公网入口。
2. 只读采集容量与依赖信息，核对 AWS 官方资源、费用与迁移限制。
3. 设计最小完整部署、数据切换与回退边界，明确现有脚本需补齐之处。
4. 定义分层验收和本机断开后的独立运行验证，交付设计文档。

## 约束

- 保留现有公网 IP、HTTPS 和 viewer/admin 权限语义。
- 密钥不进入计划、命令输出或 Git；线上只存 /etc/haike/haike.env。
- 不触碰其他会话未提交修改；发布版本另行冻结。
- 方案不假设当前 t3.micro 足以容纳全套依赖。
- 本轮不运行构建、全量测试、真实模型调用或破坏性命令。

本文件创建后固定；复评与补充记录在 addendum.md。
