# T52 对象与关系适用性约束

目标：将充电关系原型接入正式事实抽取、候选校验和发卡流程，验证 T52 以及相邻和跨品类案例。

1. 阅读正式链路和测试夹具，确认原型可复用边界。
2. 设计带原话依据的关系事实，以及经官方资料审核的候选适用范围。不增加独立意图分类调用。
3. 实现候选与发卡约束，考虑更正、否定、后果和历史卡片。
4. 运行相关单测和 lint，再进行真实模型与知识库的 HTTP 链路验证。
5. 保存中文过程、逐案结果、失败原因和最终结论。区分程序约束有效与事实抽取仍可能出错。

验收：充电盒自身不进电不能进入泵不开机流程；正常泵不开机、盒给泵充电、直接充电和非充电案例不被错误拦截。

不部署、不提交。既有并行会话改动不动。
