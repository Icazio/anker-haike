# 管理页面访问延迟

问题：用户通过 AWS 公网入口查看会话与工作台时，等待较长时间才展示数据。

目标：比较直接后端、本机 Vite 与公网链路耗时，定位可复现的瓶颈并完成已授权范围内的修复。

约束：测量只读接口，不调用模型或知识库，不修改业务数据；凭据只从 .env 读取且不输出。保留管理权限隔离，不修改其他会话的文件与 Git 改动。前端构建、Docker 构建和全量测试遵守项目限制。

阶段：

1. 建立页面实际接口与资源的耗时基线，记录响应体积和等待/传输耗时。
2. 比较并排序网络转发、认证/资源加载和后端查询/载荷假设；一次只改变一个变量。
3. 在正确调用边界增加回归检查，修复已证实的瓶颈。
4. 执行相关验证，重复原请求确认改善，交付原因、结果和剩余限制。

开发开始后保持本文件不变，复评写 addendum.md。
