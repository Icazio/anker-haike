# T52最小诊断图谱试验

目标：用T52验证部件关系、会话事实和操作适用性图能否阻止对象串路，并保留正常及跨部件操作。

范围：吸奶器T8D04充电问题；独立原型，不接入生产路由，不改已有产品别名、生成知识或数据库。无需图数据库和新增依赖。

步骤：核对现有官方资料；建立带出处的产品关系和操作条件；实现会话事实引用、目标与操作判定；离线重放错误候选及对照场景；真实模型从原文抽取事实后重新判定；生成中文记录和可操作HTML演示。

验收：T52拒绝泵不开机分支；泵明确不开机和盒有电但不给泵充电可以进入各自流程；未知、矛盾、用户纠正、临时供电有独立结果；模型高置信度不能覆盖缺少依据；逐项记录失败，不用预设正确事实冒充真实模型效果。
