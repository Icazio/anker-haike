# 恢复公网访问并临时取消认证

## 目标

恢复公网客户页面与管理页面访问。用户已明确要求两个入口都免登录，按此范围调整代理认证。

## 步骤

1. 用匿名和认证请求建立当前可复现的访问失败信号，核对本机前端、后台和转发连接。
2. 区分本机服务、SSH 转发、云端代理三类故障，恢复已授权服务。
3. 修改公网代理取消两个入口的登录要求，保持管理员操作身份可追踪，移除外部伪造身份头。
4. 验证匿名页面、API、数据压缩与身份转发，记录恢复认证方法。
